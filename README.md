Este portfólio reúne projetos práticos desenvolvidos ao longo do curso **Desenvolvedor Java — SENAI**.

## ⭐ Projetos em destaque

### 🍱 Vianda Marmitex — Cardápio Digital

Aplicação web desenvolvida para apresentar produtos e facilitar a realização de pedidos.

**Principais funcionalidades:**

- Cardápio responsivo e organizado.
- Pesquisa de produtos.
- Sacola de compras interativa.
- Adição e remoção de itens.
- Cálculo automático do valor total.
- Opções de entrega e retirada.
- Geração de mensagens de pedidos para WhatsApp.

🔗 [Acessar projeto online](https://robsonamr.github.io/vianda-marmitexx/)

📁 [Repositório do projeto](https://github.com/RobsonAMR/vianda-marmitexx)

### 🛡️ Sistema Orion — Bootstrap + JavaScript

Mini-projeto desenvolvido para integrar componentes do Bootstrap 5 com manipulação dinâmica do DOM utilizando JavaScript puro.

**Principais funcionalidades:**

- Interface responsiva utilizando Bootstrap 5.
- Card com imagem, título, status e botão.
- Alternância entre estados ONLINE e OFFLINE.
- Alteração dinâmica de textos e cores.
- Manipulação de classes CSS via JavaScript.
- Eventos de clique utilizando `addEventListener`.
- Separação do projeto em HTML, CSS e JavaScript.

📁 [Acessar Sistema Orion](./Sistema%20Orion%20HTML%20%2B%20Bootstrap%2BJS/)

## 🚀 Como executar os projetos

### 1. Baixe o repositório

Acesse o repositório e selecione:

`Code → Download ZIP`

Ou utilize o Git:

```bash
git clone https://github.com/RobsonAMR/Curso-Desenvolvedor-Java---SENAI.git
```

### 2. Abra o projeto desejado

- **Java:** siga as instruções presentes no README do respectivo projeto.
- **Portugol:** abra o arquivo `.por` no Portugol Studio ou no Portugol Webstudio.
- **Call of Duty:** abra o arquivo `site.html` da versão desejada no navegador.
- **Vianda Marmitex:** execute o arquivo `index.html` no navegador.
- **Sistema Orion:** abra o arquivo `index.html` ou execute utilizando Live Server no VS Code.

> **Observação:** mantenha os arquivos e as pastas de cada projeto em suas respectivas estruturas. Projetos que utilizam bibliotecas via CDN precisam de conexão com a internet para carregar esses recursos.
