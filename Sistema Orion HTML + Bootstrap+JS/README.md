## 📌 Sobre o Projeto

O **Sistema Orion** é uma aplicação web simples e interativa que simula a ativação e desativação de um sistema.

O projeto foi desenvolvido com o objetivo de colocar em prática conceitos fundamentais de desenvolvimento web, utilizando HTML, CSS, Bootstrap 5 e JavaScript.

A interface apresenta um Card responsivo que altera seu conteúdo e sua aparência conforme a interação do usuário.

---

## ✨ Funcionalidades

✅ Interface moderna e responsiva

✅ Card estilizado com Bootstrap 5

✅ Botão para ativar e desativar o sistema

✅ Alteração dinâmica de textos

✅ Indicador de status ONLINE e OFFLINE

✅ Mudança automática de cores

✅ Manipulação do DOM com JavaScript

✅ Eventos utilizando addEventListener

✅ JavaScript puro, sem jQuery

## ⚙️ Como Funciona

O Sistema Orion possui dois estados principais.

### 🔴 Sistema Desativado

- Status OFFLINE.
- Botão "Ativar Sistema".
- Interface com aparência padrão.
- Mensagem informando que o sistema está desativado.

### 🟢 Sistema Ativado

- Status ONLINE.
- Botão "Desativar Sistema".
- Alteração das cores do Card.
- Mensagem confirmando a ativação.

As alterações acontecem instantaneamente, sem recarregar a página.

## 🧠 Conceitos Praticados

Durante o desenvolvimento foram aplicados:

- Estruturação semântica com HTML5.
- Estilização com CSS3.
- Desenvolvimento responsivo com Bootstrap.
- Conceito Mobile-First.
- Seleção de elementos com getElementById().
- Manipulação de classes com classList.
- Eventos de clique com addEventListener().
- Estruturas condicionais com if e else.
- Controle de estado com variáveis booleanas.
